# Tekstury interfejsu OpenMW

Strzałki `omw_menu_scroll_{left,right,up,down}.png` pochodzą z projektu OpenMW (`files/data/textures/omw_menu_scroll_*.dds`,
skórki `MW_ArrowLeft/Right/Up/Down` w `files/data/mygui/openmw_list.skin.xml`), przekonwertowane do PNG bez zmian.
Są częścią danych OpenMW (GPLv3, jak całe repozytorium), a nie zasobami Bethesdy.
