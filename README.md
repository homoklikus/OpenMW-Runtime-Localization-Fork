An unofficial fork of OpenMW 0.51.0 adding runtime localization support
for TES3 content while preserving canonical source records and technical
identifiers.

Localization data is supplied by an external localization layer.
This repository does not contain game localization data, Bethesda assets,
or translated Morrowind content.
