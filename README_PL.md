OpenMW — Runtime Localization Fork
==========================================

[English](README.md) | **Polski**

Nieoficjalny fork OpenMW 0.51.0 dodający obsługę lokalizacji TES3
w czasie działania silnika, przy zachowaniu kanonicznych rekordów źródłowych
oraz identyfikatorów technicznych.

Dane lokalizacyjne są dostarczane przez zewnętrzną warstwę lokalizacji.
To repozytorium nie zawiera danych lokalizacyjnych gry, zasobów Bethesdy
ani przetłumaczonej zawartości Morrowinda.
